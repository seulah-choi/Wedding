# 구글 시트 연동 설정 가이드

구글 시트에 쌓인 실제 판매 데이터를 대시보드가 자동으로 읽고, 팀원들은 **링크 하나로** 최신 화면을 봅니다.
처음 한 번만 설정하면 되고, 대략 10분 정도 걸립니다.

```
구글 시트 (RawData 시트)  →  Apps Script 웹앱  →  팀원 (회사 구글 계정으로 로그인)
```

---

## 1. 데이터 시트 만들기
1. 회사 구글 계정으로 [Google Drive](https://drive.google.com) 를 엽니다.
2. `sheet_template.xlsx` 를 업로드한 뒤, 업로드한 파일을 열고 **파일 > Google 스프레드시트로 저장**을 누릅니다.
   - 먼저 샘플로 확인해 보고 싶다면 `sales_data.xlsx` 를 같은 방법으로 엽니다.
3. 시트 이름은 **`RawData`** 로 둡니다. 첫 줄 헤더는 아래와 같아야 합니다 (순서는 상관없음).

   | 연월 | 팀 | 담당자 | 거래처 | 제품 | 수량 | 매출액 |
   |---|---|---|---|---|---|---|
   | 2026-10 | 영업1팀 | 김민준 | 한빛유통 | 프리미엄 A | 51 | 2372010 |

   - `연월` 은 `2026-10` 같은 텍스트로 넣어도 되고, 날짜 형식으로 넣어도 됩니다.
   - `수량` 은 없어도 됩니다. 나머지 6개 컬럼은 꼭 있어야 합니다.

## 2. 대시보드 코드 넣기
1. 시트 메뉴에서 **확장 프로그램 > Apps Script** 를 엽니다.
2. 왼쪽 `Code.gs` 의 기존 내용을 지우고 `apps-script/Code.gs` 내용을 붙여넣습니다.
3. 왼쪽 **파일 옆 `+` > HTML** 을 눌러 파일 이름을 **`index`** 로 만들고 (`.html` 은 자동으로 붙음),
   기존 내용을 지운 뒤 `apps-script/index.html` 내용을 붙여넣습니다.
4. 💾 저장 아이콘을 누릅니다.

## 3. 웹앱으로 배포하기
1. 오른쪽 위 **배포 > 새 배포** 를 누릅니다.
2. 톱니바퀴 ⚙️ 에서 유형으로 **웹 앱** 을 고릅니다.
3. 아래처럼 설정합니다.

   | 항목 | 설정값 | 이유 |
   |---|---|---|
   | 설명 | `영업 대시보드 v1` | 아무거나 |
   | 다음 사용자 인증 정보로 실행 | **웹 앱에 액세스하는 사용자** | 보는 사람 각자의 권한으로 시트를 읽음 |
   | 액세스 권한이 있는 사용자 | **(회사명) 내 모든 사용자** | 회사 계정만 접속 가능 |

4. **배포** 를 누르면 권한 확인 창이 뜹니다. **액세스 승인** 을 누르고 본인 계정을 선택한 뒤 **허용**을 누릅니다.
   - 이 스크립트는 **이 스프레드시트 하나만** 읽도록 제한돼 있습니다 (`@OnlyCurrentDoc`).
5. 화면에 나온 **웹 앱 URL** (`https://script.google.com/a/macros/.../exec`) 을 복사합니다. 이 주소가 대시보드 링크입니다.

## 4. 팀원과 공유하기
1. 구글 시트 오른쪽 위 **공유** 를 누르고, 대시보드를 볼 팀원(또는 팀 그룹 메일)을 **뷰어** 로 추가합니다.
   - 데이터를 입력하는 사람만 **편집자** 로 추가합니다.
2. 3단계에서 복사한 웹 앱 URL 을 팀원들에게 보냅니다.
3. 팀원이 처음 접속하면 권한 확인 창이 한 번 뜹니다. **허용** 을 누르면 됩니다.

> 🔒 **누가 볼 수 있나?** 시트 공유 목록에 있는 회사 계정만 볼 수 있습니다.
> 퇴사자나 담당 변경이 생기면 **시트 공유에서 빼기만 하면** 대시보드 접근도 함께 막힙니다.

---

## 평소 사용법
- **데이터 추가**: `RawData` 시트 맨 아래에 새 달의 행을 붙여넣습니다. ERP에서 내보낸 엑셀을 같은 컬럼 순서로 붙여넣어도 됩니다.
- **화면 갱신**: 대시보드에서 **새로고침** 버튼을 누르거나 페이지를 다시 엽니다. 선택해 둔 팀/담당자 필터는 그대로 유지됩니다.
- 진행 중인 분기(예: 10월만 있는 4분기)는 **월평균**으로 전분기와 비교합니다.

## 대시보드 화면을 고쳤을 때
1. `dashboard.html` 을 수정한 뒤 `python3 build_apps_script.py` 를 실행합니다. 그러면 `apps-script/index.html` 이 새로 만들어집니다.
2. Apps Script 편집기의 `index.html` 에 새 내용을 붙여넣고 저장합니다.
3. **배포 > 배포 관리 > ✏️ 수정 > 버전: 새 버전 > 배포** 를 누릅니다. 이렇게 하면 **링크가 바뀌지 않습니다.**
   - "새 배포"를 누르면 링크가 새로 생기니 주의하세요.

## 문제 해결
| 증상 | 해결 |
|---|---|
| "구글 시트를 읽을 수 없습니다 … 권한" | 그 팀원이 시트 공유 목록(뷰어 이상)에 있는지 확인합니다. |
| "필수 컬럼이 없습니다: 매출액" | `RawData` 첫 줄 헤더 이름을 확인합니다 (띄어쓰기, 오타). |
| 팀원이 "액세스 권한 필요" 화면을 봄 | 시트에 뷰어로 공유돼 있어도 계속 이 화면이 뜬다면, 배포 설정의 실행 사용자를 **나** 로 바꿉니다. 이때는 회사 계정이면 누구나 볼 수 있게 되므로, 액세스 권한을 **특정 사용자/그룹**으로 좁힐 수 있는지 관리자에게 확인하세요. |
| 데이터가 많아 느림 (수만 행 이상) | 오래된 연도는 별도 시트로 옮기세요. 대시보드는 `RawData` 시트만 읽습니다. |
